Vista de cliente del restaurante y de la tienda, compartiendo identidad y navegación.

**Solo revisión.** La tienda es una demostración: no acepta pagos ni pedidos reales. No se publica ninguna contraseña, dato de cliente ni almacenamiento de administración. Las versiones anteriores se conservan por separado. La publicación de revisión no sustituye la web del restaurante.
